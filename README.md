#  mXplore — NASA Space Apps Challenge Project

> An immersive space exploration project developed for the NASA International Space Apps Challenge.

---

##  Overview

**mXplore** is an interactive space exploration application designed to visualize orbital telemetry and mission data. Built during the NASA Space Apps Challenge, it aims to make complex aerospace concepts accessible and engaging through interactive graphics and real-world astronomical data.

---

##  Key Features

* **Interactive Telemetry Visualization:** Real-time visual tracking of spacecraft trajectories.
* **Custom Flight Physics:** Custom-built mechanics for realistic movement handling.
* **Comprehensive Datasets:** Integrated NASA open datasets for astronomical visual accuracy.
* **Team Pitch & Demo:** Complete presentation video demonstrating key project workflows.
