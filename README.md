# 🚀 mXplore — NASA Space Apps Challenge Project

> An immersive web-based space exploration project developed for the NASA International Space Apps Challenge.

---

## 🌌 Overview

**mXplore** is an interactive web application designed to visualize orbital telemetry and mission data. Built with modern web technologies during the NASA Space Apps Challenge, it makes complex aerospace concepts accessible and engaging directly in the browser through interactive graphics and real-world astronomical data.

---

## ✨ Key Features

* **Interactive Telemetry Visualization:** Real-time visual tracking of spacecraft trajectories.
* **Responsive Web Interface:** Clean UI built with custom CSS and dynamic JavaScript interactions.
* **Comprehensive Datasets:** Integrated NASA open datasets for astronomical visual accuracy.
* **Team Pitch & Demo:** Complete presentation video demonstrating key project workflows.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Version Control:** Git & Git LFS for large media asset management
* **Data Sources:** NASA Open APIs
